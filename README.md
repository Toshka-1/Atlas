# Atlas hors ligne

Copie du carnet de sèche Atlas qui garde tout sur l'iPhone, même sans réseau et onglet fermé.
Ouvrir https://toshka-1.github.io/Atlas/ dans Safari, puis Partager → Sur l'écran d'accueil.
Les saisies passent dans Atlas par copier-coller (carte « Envoyer vers Atlas »).
Aucune donnée personnelle n'est dans ce dépôt : elles restent sur le téléphone.
